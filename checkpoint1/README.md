# Statistical Methods for Learning (BIOSTAT 707)

This repository is for BIOSTAT 707 programming assignments. Each checkpoint lives in its own folder.

## Checkpoint 1

Everything for Checkpoint 1 is in this `checkpoint1/` folder.

Run `pixi run --locked checkpoint1` from inside this folder (`checkpoint1/`) after `data/set-a/` (4000 records) and `data/Outcomes-a.txt` are already in place here. The script writes `output/set-a_long.csv`, `output/set-a_wide.csv`, `output/table1.csv`, `output/outcomes.csv`, `output/missingness_map.png`, and `output/missingness_vs_death.csv`. Interpretation is in `checkpoint1_writeup.md`.
