Run `pixi run --locked checkpoint1` from the repo root after `data/set-a/` (4000 records) and `data/Outcomes-a.txt` are already in place. `checkpoint1.py` checks those paths, merges the skinny files into a long table, builds a wide table (48h count/first/last/min/max/mean; high-frequency variables also get 0–24h and 24–48h summaries), writes Table 1 and an outcome summary, and plots missingness. Interpretation is in `checkpoint1_writeup.md`.

Set-A has 4000 stays and 13.85% in-hospital death (554). Deaths are older, with higher SAPS-I/SOFA, more MICU and fewer CSRU. Height is missing for about half of stays. Troponin and liver labs are ordered more often in patients who die; unmeasured `RespRate` tracks ventilation (7.9% vs 16.1% mortality). The run writes `output/set-a_long.csv`, `output/set-a_wide.csv`, `output/table1.csv`, `output/outcomes.csv`, `output/missingness_map.png`, and `output/missingness_vs_death.csv`.
